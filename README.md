# Bean & Leaf — Menu Costing & Pricing App

A menu costing (HPP / COGS) and pricing calculator for a coffee shop. Plain HTML, CSS and JavaScript in four files, with no libraries and no installation.

## How to open
1. Keep `index.html`, `style.css`, `data.js` and `app.js` in the same folder.
2. Double-click `index.html` to open it in Chrome, Edge, Firefox or Safari.
3. The app starts with sample data. Edit it, or clear it in **Costs & Settings → Data**.

No server or internet connection is needed. Fonts load from Google Fonts when online and fall back to system fonts offline.

## How it works
- **Ingredients**: enter each ingredient once with its pack size, unit and price. Recipes reuse it, so a price change updates every menu instantly.
- **Menus**: build recipes from your ingredients. Use "Portions per recipe" for batch items like a tray of 12 muffins.
- **Costs & Settings**: monthly overhead, target margin, rounding, delivery commission, currency, categories and data tools.
- **Print / Save as PDF**: prints a clean report. Choose "Save as PDF" in the print dialog.

## Back up your data
Data is saved automatically in this browser only. Use **Costs & Settings → Data → Export backup** regularly, and **Import backup** to restore it on another browser or device.
